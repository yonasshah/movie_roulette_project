# Movie Roulette

Movie Roulette is a Django web app that helps users discover movies and shows, build watchlists, review content, follow other users, and interact through a social activity feed.

## Features
- Randomized movie/show discovery
- Search and content detail pages
- User accounts and profiles
- Watchlists and custom public/private lists
- Activity feed with likes, comments, threaded replies, and votes
- Notifications for social activity
- Mobile-responsive UI

## Tech Stack
- Python
- Django
- JavaScript
- Tailwind CSS / Bootstrap if used
- SQLite/PostgreSQL
- TMDb API
